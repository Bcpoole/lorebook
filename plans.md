# GUI

## Basics

- input box and show response
    - toggle between streaming or get all at once
- show token usage and time
- show graph structure and node details
- show each agent in a UX friendly UI (SPA-like different tabs within the page?)

## Experimentation

- experiment tab - show different prompts and responses, allow tweaking and saving prompts, A/B testing, etc. Examples:
    - temperature and top_p variations
    - prompt template variations (some type of substition mechanism to swap out different prompt versions and test them against each other)
    - allow to set seed, but default to `9111993` for reproducibility

## Pretty + Advanced

- use a nice Python web framework like FastAPI or Flask for the backend
- display an avatar for each agent (load from a local png file, each agent gets their own sudirectory, have different images based on state, current activity, mood, and silly things like temperature etc. with it defaulting to the base avatar when not specified. The smaller tweaks should have a parent structure instead of just defaulting to the base)
- Character, setting, and object generation allow to generate image via local Stable Diffusion Autoamtik 1111 API endpoint and display it in the UI. Prompt should be auto generated by the LLM into a Stable Diffsuion Automatik compatible prompt, but allow for user tweaking and re-generation. Store the prompt and image together as part of the asset data structure.
